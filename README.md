# mikegofficial.xyz

Personal link-in-bio website for **Michael Gnagy** ([@mikegofficial](https://mikegofficial.xyz)).

Hosted on **GitHub Pages** at [mikegofficial.xyz](https://mikegofficial.xyz).

## Stack

- **Zero-build static page**: Built with semantic HTML5 and vanilla CSS.
- **Design**: Austin limestone & 1992 retro-tech aesthetic with daylight and night-drive themes.
- **Typography**: Space Grotesk, Plus Jakarta Sans, and IBM Plex Mono (via Google Fonts).
- **Icons**: Custom lightweight SVGs with accessible labeling.
